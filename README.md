# Visus: versões

Instaladores do **Visus**, um app para Windows que transmite a tela ou uma janela do PC, com o som,
em qualidade máxima, para quem você convidar. Funciona de qualquer rede, sem abrir porta no
roteador e sem VPN. O código do Visus é privado; este repositório só guarda os instaladores e o
`latest.json` que o próprio app consulta para se atualizar.

## Baixar

Pegue o `Visus_X_x64-setup.exe` mais recente na página de
[Releases](https://github.com/NVanitas/visus-releases/releases/latest). A instalação é só para o seu
usuário do Windows (não pede senha de administrador). Quem já tem o Visus recebe as versões novas
sozinho, em Ajustes > Sobre.

## Segurança das atualizações

Cada instalador é assinado digitalmente (minisign). O Visus só instala uma atualização se a
assinatura conferir com a chave pública que vem dentro do app; um arquivo adulterado é recusado.
